# Novel Logger
Novel Logger is a web application for tracking your reading progress across novels. It allows you to bookmark your latest chapter, save memorable chapters, and add notes so you don’t forget where you left off.

The app is designed to minimize manual cleanup and reduce mental overhead when managing multiple novels at once.

## Features
-  Bookmark your latest chapter per novel  
-  Save memorable chapters with optional notes  
-  Automatically replaces prior unsaved “latest” bookmarks  
-  Track reading progress using novel status and notes  
-  User accounts with private libraries  

## Purpose
This project was built to practice real-world CRUD workflows, Entity Framework Core modeling, and ASP.NET Core MVC patterns while solving a practical problem for readers.

## Tech Stack
- ASP.NET Core MVC  
- Entity Framework Core  
- ASP.NET Identity  
- SQL Server
